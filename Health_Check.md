# Linux Health Check

## Check uptime

```bash
uptime
```

---

## Check disk usage

```bash
df -h
```

---

## Check memory

```bash
free -m
```

---

## Check CPU load

```bash
top
```

---

## Check services

```bash
systemctl --failed
```

---

## Check logs

```bash
journalctl -p err
```

---

## Check network

```bash
ip addr

ip route

ping
```
